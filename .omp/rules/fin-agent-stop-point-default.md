# Стоп-точка по умолчанию

`/ship` останавливается на `stop-before-commit`, если контракт плана не назвал другую
стоп-точку: реализация, тесты и независимое ревью идут автоматически, коммит и всё
после (MR, dev, prod, мерж, деплой) ждут явного «продолжай» оператора.

Обоснование проектное: правило задаёт контракт плана, а не тип проекта. Формулировка
перенесена сюда из копии `dev-flow`, которую сняла поставка плагином (в payload
`ontoship` 0.4.1 утверждение «умолчание» отсутствует — см. отчёт о поставке).
