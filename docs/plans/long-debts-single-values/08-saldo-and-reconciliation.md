# 08: Сальдо, сверка и неполнота прогноза

**What to build:** сальдо по контрагенту и сверка с выпиской идут по канону остатка, поэтому
сверка **может сойтись**: наблюдение из выписки, совпавшее с расчётом на дату, не оставляет
открытого вопроса и не делает прогноз неполным (сегодня расхождение с выпиской не
закрывается никогда — расчёт не видит начисленных процентов). Расхождение остаётся открытым
вопросом с названной причиной: правило начисления движка не совпало с правилом кредитора —
и закрывается правкой условий сделки или записью факта, а не правкой числа. Запись внешних
начислений (комиссии, страховки, пени, издержки) — не эта работа: она в заявке про пени и
начисления.

**Blocked by:** 06 — канон остатка.

- [ ] Синтетика: наблюдение, равное расчётному остатку на дату, не создаёт открытого вопроса и не делает прогноз неполным.
- [ ] Синтетика: наблюдение, разошедшееся с расчётом, остаётся открытым вопросом с разницей, и прогноз помечен неполным.
- [ ] Сальдо по контрагенту считается по канону — начисленное входит в него.
- [ ] Документация сверки перестала утверждать, что сошедшейся сверки не бывает.
- [ ] `python3 -m pytest tests/` зелёные; `finance_core/README.md` и `CONTEXT.md` описывают сверку на новом каноне.
