# 01: Окно — конец окна и его причина

**What to build:** прокат кончается там, где кончается вопрос, а не на фиксированных
50 годах. Окно — минимум из трёх: последний платёж по сделкам с остатком (второй
приоритет продлевает окно только при согласии владельца), конец видимых доходов,
`max_months`. Причина конца окна видна снаружи объявленным набором — «долги закрыты»,
«кончились доходы», «кончился предел месяцев». Регулярные расходы и сделки без числа
платежей (график процентом от остатка) окно не продлевают: у них последнего платежа нет,
для них предел — доходы и `max_months`.

**Blocked by:** None (can start immediately).

- [ ] Синтетика: долг с графиком на 24 месяца и бесконечный регулярный расход — окно кончается закрытием долга, причина «долги закрыты» (сегодня окно — 600 месяцев).
- [ ] Синтетика: доходы кончаются раньше долга — окно кончается концом доходов, причина названа.
- [ ] Синтетика: долг без числа платежей — окно упирается в `max_months`, причина названа.
- [ ] Второй приоритет с согласием владельца продлевает окно до своего закрытия; без согласия — не продлевает.
- [ ] `python3 -m pytest tests/` зелёные; `finance_core/README.md` и `CONTEXT.md` называют причину конца окна.
