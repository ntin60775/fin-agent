# 01: Окно — конец окна и его причина

**What to build:** прокат кончается там, где кончается вопрос, а не на фиксированных 50 годах.
Окно — минимум из трёх: последний платёж по сделкам с остатком (второй приоритет продлевает
окно только при согласии владельца), конец видимых доходов, `max_months`. Причина конца окна
видна снаружи объявленным набором — «долги закрыты», «кончились доходы», «кончился предел
месяцев». Регулярные расходы и сделки без числа платежей (график процентом от остатка) окно не
продлевают: у них последнего платежа нет, для них предел — доходы и `max_months`.

**Решения**

- **Чем измеряется «последний платёж по долгам» — по графику, а не по прокату.** График
  (последнее вхождение сделки с остатком) не зависит от свободных денег, а прокат зависит:
  окно стало бы результатом того, что само от него зависит. График при этом — гарантированный
  верх: досрочки закрывают долг раньше, но никогда позже.
  *Отклонено:* по прокату — циклическая зависимость (14/35); максимум из двух — та же связка,
  только мягче (17/35).
- **Окно — минимум с концом видимых доходов, и это названо причиной.** Месяцы за концом
  доходов были бы выдумкой (деньги тратятся из накопленного остатка, а не из дохода), поэтому
  окно там и кончается. Следствие, которое обязано быть видно: срок с досрочками может
  оказаться за окном — тогда он назван причиной («доходы кончаются раньше»), а не пропущен;
  ответ «дата есть для любого графика» держит срок по графику (тикет 02), который доходов не
  требует вовсе.
  *Отклонено:* окно только по долгам, а месяцы за концом доходов помечать допущением — это
  возвращает ровно тот дефект, который чиним: бюджет месяца растёт без дохода (26/35);
  два окна (данных и долгов) — вдвое больше понятий ради того же ответа (25/35).
- **Причина конца окна — одно значение из объявленного набора, по порядку важности.**
  Порядок: долги закрыты → кончились доходы → кончился предел месяцев. Совпадение двух причин
  безвредно, а первый по порядку ответ полезнее: если долги закрылись, вопрос задан именно об
  этом.
  *Отклонено:* набор значений (31/35) — честнее про совпадения, но владельцу нужен один ответ;
  значение плюс отдельный флаг «доходы кончились раньше» (24/35) — третье понятие ради
  редкого случая.
- **Ступени прогноза считаются внутри окна; за окном — «не достигнута» с причиной.**
  Ступень 2 (свободные деньги) может лежать за концом окна; показывать её как достигнутую
  нельзя, а молчание выдало бы окно за весь срок.
  *Отклонено:* ступени независимо от окна (21/35) — тогда отчёт обещает то, чего в расчёте
  нет.

**Blocked by:** None (can start immediately).

- [ ] Синтетика: доходы кончаются раньше долга — окно кончается концом доходов, причина названа, и срок с досрочками за окном назван причиной, а не пропущен.
- [ ] Синтетика: долг без числа платежей — окно упирается в предел месяцев, причина названа.
