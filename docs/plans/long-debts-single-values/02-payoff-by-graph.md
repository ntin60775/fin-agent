# 02: Обе даты — срок по графику рядом со сроком с досрочками

**What to build:** у вопроса «когда выйду из долгов» два названных ответа. Первый — **срок по
графику**: когда сделки закроются своими платежами, без досрочек; считается независимо от
связки с кассой, поэтому есть всегда. Второй — **срок с досрочками**: как сегодня, при текущих
свободных деньгах. «По графику не закрывается» говорится прямо, причиной рядом с датой, а не
пустым полем: платёж, не покрывающий проценты, — это честное «никогда», и оно должно быть
видно.

**Решения**

- **Срок по графику считается тем же прокатом сделок, но без бюджета досрочек.** Один проход
  по существующему коду (замер — 0,02 с) честно учитывает ставку, базу начисления, копилки и
  просроченные вхождения. Аналитика «последнее вхождение по графику» дешевле, но врёт там, где
  это важнее всего: у долга, платёж которого не покрывает проценты, график кончится, а долг
  останется.
  *Отклонено:* аналитически по последнему вхождению (22/35) — ложная дата вместо честного «не
  закрывается».
- **«Не закрывается» — одна формулировка, как у обязательного графика.** Причина та же, что у
  `stalled`: за отведённые месяцы долг не закрылся. Различать «платёж меньше процентов» и
  «график кончился, а остаток остался» полезно, но это новая логика ради диагностики, которой
  приёмка плана не требует; если зоне понадобится — отдельным тикетом.
  *Отклонено:* различать две причины (30/35) — на балл ниже и на одну ветку больше; узкая
  формулировка про проценты (18/35) — приписывает долгу одну из причин, не проверяя.
- **Обе даты живут в прокате; прогноз строит из них даты-цели.** Иначе к одному ответу ведут
  два пути: `roll_deals` отдал бы срок по графику, а `roll_months` — нет, и зона выбирала бы,
  кого спрашивать.
  *Отклонено:* только в прогнозе (26/35) — прокат остаётся без ответа на свой же вопрос;
  отдельной функцией снаружи (26/35) — третий вход туда же.
- **Вторая дата считается всегда, без флага.** Один проход по графику стоит 0,02 с — дешевле,
  чем режим, который надо не забыть включить; и ответ есть у каждого расчёта, а не только у
  спросившего.
  *Отклонено:* по флагу (27/35) — два режима ради двух сотых секунды.
- **Долг, закрытый к началу окна, говорит об этом, а не молчит.** Дата — первый месяц окна и
  причина «закрыт к началу проката: закрывать нечего»: тот же язык, что у второго приоритета в
  прогнозе.
  *Отклонено:* пустая дата без причины (20/35) — неотличимо от «не посчитали».

**Blocked by:** 01 — окно задаёт горизонт, в котором обе даты имеют смысл.
