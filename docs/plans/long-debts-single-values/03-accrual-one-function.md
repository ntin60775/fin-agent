# 03: Начисление — одна функция (подготовка)

**What to build:** начисление процентов за календарный месяц становится **одной функцией**,
которой пользуется прокат. Сегодня правила начисления живут внутри месячного цикла проката
(дневная ставка — по дням, платёж дня уменьшает остаток до начисления за этот день;
годовая — от остатка на начало месяца; округление до копейки вверх-вниз по правилу месяца)
и нигде больше не переиспользуются. После тикета у начисления один носитель: канон остатка
(тикет 06) возьмёт ту же функцию, поэтому прокат и остаток на дату сойдутся по построению,
а не по совпадению.

**Поведение не меняется** — это подготовка: ни одна цифра в существующих тестах не должна
сдвинуться.

**Blocked by:** None (can start immediately).

- [ ] Прокат считает проценты выделенной функцией; ожидания существующих тестов не переписаны ни в одном месте.
- [ ] Функция покрыта тестом сама по себе: дневная база (включая порядок «платёж дня до начисления дня») и годовая (остаток на начало месяца, платежи внутри месяца начисления не меняют).
- [ ] `python3 -m pytest tests/` зелёные.
