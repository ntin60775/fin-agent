# 09: Хвосты ревью — сборник неблокирующих замечаний

## Зачем

Сборник неблокирующих замечаний независимых ревью тикетов 01 и 02. Пополняется
по ходу тикетов 03–08 (оператор дописывает новые хвосты до старта рана) и
выполняется последним, после 08. При разной природе проверки на исполнении
делится на два рана: код — прогоны, доки — линт.

Каждый пункт проверен по состоянию main на 2026-09-25: уже закрытые вынесены
одной строкой в «Уже закрыто» и в работу не идут.

## Код

«не закрывается» рядом.

против `first_priority = месяц без причины` (`forecast.py:421-424`; freedom на
пустом наборе ставится в `roll.py:838-839`).
