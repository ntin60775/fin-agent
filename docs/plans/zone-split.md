# План: разделение на две зоны

**Goal** — вынести движок расчёта из приватной финансовой зоны в отдельный
репозиторий, чтобы личные данные не смешивались с кодом, а каждое изменение
движка проходило полный цикл разработки.

**Done** — движок живёт здесь и покрыт синтетическими тестами; финансовая зона
подключает его как библиотеку, её сценарные тесты зелёные; линтер KB чист.

**Scope** — этот репозиторий целиком; в финансовой зоне: `finance_core/`,
`scenarios/`, `tests/`, `.omp/`, `docs/`.

**Constraints** — данные не покидают финансовую зону; движок не знает ни одного
личного числа.

**Context** — решение [zone-split.md](../decisions/zone-split.md). В первой версии
движка личное имя просочилось в публичный API — переименовано в `optional_cap`;
отсюда правило «движок обязан оставаться чистым».

## Тикеты

1. **Каркас** — репозиторий и пакет системы (навыки, команды, правила). *готово*
2. **Движок** — перенос `finance_core`, обезличивание, синтетические тесты,
   `pyproject.toml`. *готово*
3. **База знаний** — `docs/`, онтология, реестр команд, глоссарий, решения. *готово*
4. **Связка** — финансовая зона подключает движок как библиотеку, сценарные тесты
   с реальными цифрами остаются там, дубли убираются. *готово* — пакет поставлен
   редактируемым (`pip install -e`, проверено `pip show finance-core`), локальной
   копии движка в зоне нет, 19 сценарных тестов зелёные.
5. **Проверка** — тесты обоих репозиториев, линт KB, поиск, коммиты в оба. *готово* —
   182 синтетических и 19 сценарных тестов зелёные, `gitmark lint` чист в обеих
   зонах, реестр команд синхронен, индекс поиска собран.
