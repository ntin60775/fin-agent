# 05: Правило даты дыры

**What to build:** у стартовой дыры — дыры, предшествующей первым событиям, —
записано одно правило, и оба пути его держат: окно известно (`roll_cash`) →
дата равна началу окна; окна нет (`run()`) → None: движок не спрашивает
«сегодня» и не выдумает, «когда» началось. Сегодня два теста фиксируют разное
поведение без общего правила: `test_hole_comes_from_the_outside` (None) и
`test_roll_cash_hole_on_starting_negative_balance` (дата окна); README
описывает только `None` для `Result.hole_date`, у `CashMonth.hole_date`
оговорки нет — «правило одно на оба пути» нарушено на уровне формулировок.
