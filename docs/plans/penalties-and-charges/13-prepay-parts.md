# 13: Досрочка и стратегия с частями

**Суть.** Досрочка — платёж по сделке, и правило распределения у неё то же, что
у планового: одно правило на сделку не дробится на «плановое» и «внеплановое».
Стратегии меряют сделки, а не строки разбивки одного долга.

**Сегодня.** Досрочка гасит бегущий остаток сделки (`_targets`,
`finance_core/roll.py:1158`); лавина ранжирует по ставке сделки (`_rate`,
`finance_core/roll.py:295`), снежный ком — по остатку; `Deal.prepay=False`
исключает сделку из досрочки.

**Будет.** Досрочка распределяется по частям правилом зоны (как плановый
платёж). Цели досрочки остаются сделками и копилками, а не частями; ранжирование
— по сделкам (ставка сделки, остаток — канон); `prepay` действует на сделку
целиком; накопленная неустойка свободных денег не уменьшает — «сколько свободно»
нею не трогается.

**Решения грилла плана.** Исполняет R3-Q16 (досрочка — тот же платёж с тем же
правилом; ранжирование по сделкам; `prepay` про сделку; свободные деньги без
изменений). Новых решений не принимает.

**Blocked by:** 03 (распределение), 04 (части).

## Приёмка

- [ ] Синтетика: досрочка распределяется по частям правилом зоны; сумма
  распределения равна сумме досрочки — `tests/test_roll.py`.
- [ ] Синтетика: порядок лавины и снежного кома не изменился (сделки
  ранжируются по-прежнему), `prepay=False` по-прежнему уводит деньги дальше —
  `tests/test_roll.py`.
- [ ] Синтетика: накопленная неустойка не уменьшает бюджет досрочек и свободные
  деньги месяца — `tests/test_actions.py`.
