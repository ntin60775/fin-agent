# 12: Прогноз и сверка: части, пробелы, вопросы

**Суть.** Кредитор показывает долг по частям, и сверка с выпиской идёт по ним, а
не одной цифрой; неизвестное обязано оставаться пробелом. Тикет чинит отчётную
сторону: расхождение объясняется по частям, а пробелы правил делают прогноз
неполным, а не молчаливо нулевым.

**Сегодня.** Сверка — одно число (`ObservedBalance`,
`finance_core/settlements.py:277`); расхождение — одно подозрение «правило
начисления не совпало»; пробелы (`Gap`, `finance_core/roll.py:161`) — по
ставке, графику и кошельку; неполнота прогноза — `Forecast.complete`.

**Будет.** Наблюдение может быть и одной суммой, и по частям; расхождение
называет часть и причину (правило начисления, штраф, пошлина). Пробелы
расширяются: нет шкалы неустойки — неустойка не считается; нет порядка
распределения — платёж по частям не распределён. С пробелами прогноз неполный;
сошедшаяся сверка вопросов не даёт; `None` остаётся «не оценено», не нулём.

**Решения грилла плана.** Исполняет R2-Q10 (канон — сумма частей, сверка
получает разбивку, расхождение объясняется по частям, неизвестное —
`None`/пробел), R3-Q12 (нет правила — пробел, а не умолчание). Новых решений не
принимает.

**Blocked by:** 02 (формы и «правило не задано»), 04 (части), 06 (нет шкалы —
пробел).

## Приёмка

- [ ] Синтетика: наблюдение по частям сверяется по частям; расхождение по
  одной части называет её и причину, сошедшаяся сверка вопросов не даёт —
  `tests/test_forecast.py`.
- [ ] Синтетика: наблюдение одной суммой сверяется с суммой частей; расхождение
  объясняется по частям — `tests/test_forecast.py`.
- [ ] Синтетика: сделка без шкалы неустойки или без порядка распределения
  даёт пробел и делает прогноз неполным, а не нулевым — `tests/test_forecast.py`.
- [ ] Синтетика: неизвестное не подставляется нулём — признак «не оценено»
  (`None`) не выдаётся за отсутствие нехватки, ступень не объявляется
  достигнутой — `tests/test_forecast.py`.
