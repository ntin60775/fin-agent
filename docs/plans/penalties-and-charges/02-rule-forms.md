# 02: Формы правил зоны, их версии и валидация

**Суть.** Ставки, пороги, потолки и порядки распределения приходят снаружи и в
движок не вшиты — но движок обязан их понимать и проверять. Тикет заводит
**закрытый набор форм правил зоны** и валидацию книги: шкала неустойки (ступени
«от N дней просрочки — дневная ставка»), потолок («без потолка», сумма или доля
просроченной суммы), порядок распределения платежа (перестановка частей),
условие триггера (закрытый набор); правила версионируются по дате действия.

**Сегодня.** Правила — только ставки сделки и правило графика (`ScheduleRule`,
закрытый набор форм, `finance_core/settlements.py:161`); шкал, потолков,
порядков распределения и триггеров в модели нет; версий правил нет.

**Будет.** Формы правил — данные модели (закрытый набор, как `ScheduleRule`):
расширение — новая форма кодом движка, а не произвольной структурой зоны. У
каждой версии правила есть дата действия; правило без даты действует на весь
период; движок выбирает правило по дате отрезка или платежа. Валидация падает
текстами по существу: ступени возрастают и не отрицательны, потолок не
отрицателен, порядок — перестановка без повторов и со всеми частями. Правила
нет — `None` («не задано»), а не ноль; «без потолка» — явная форма, а не
отсутствие данных.

**Решения грилла плана.** Исполняет R1-Q3 (правила приходят снаружи, считает
движок), R3-Q12 (закрытый набор форм, тексты валидации, неизвестное —
`None`/пробел), R4-Q25 (версии правил по дате действия), правку 1 («без
потолка» — явная форма правила, не `None`). Новых решений не принимает.

**Blocked by:** 01 (объявленный набор частей — для порядка распределения).

## Приёмка

- [ ] Синтетика: корректные формы правил проходят валидацию; каждое нарушение
  (убывающие ступени, отрицательная ставка или потолок, порядок с повторами или
  без части) падает с текстом, называющим правило и что исправить —
  `tests/test_settlements.py`.
- [ ] Синтетика: правило с датой действия обслуживает только свои даты — прошлое
  считается правилом своей эпохи; правило без даты действует весь период —
  `tests/test_settlements.py`.
- [ ] Синтетика: отсутствие правила не подставляется нулём — признак «правило не
  задано» (`None`) отличим от «без потолка» — `tests/test_settlements.py`.
- [ ] Факт: умолчаний правил в коде движка нет (`finance_core/README.md`,
  инварианты).
