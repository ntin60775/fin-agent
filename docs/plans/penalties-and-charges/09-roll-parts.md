# 09: Прокат: части, закрытость, stalled и раскладка начисленного

**Суть.** Составной долг обязан вести себя в проекции честно: сделка
закрывается, когда погашены все её части; платёж, не покрывающий начисляемое,
даёт честное «не закрывается», а не ложный срок; равенство «прокат = канон»
выдерживается и по частям.

**Сегодня.** Закрытость входа в прокат — по телу (`_rollable`,
`finance_core/roll.py:467`), в прокате — по бегущему остатку (`_all_closed`,
`finance_core/roll.py:1212`); `stalled` — свобода не достигнута
(`finance_core/roll.py:1106`); начисленное месяца — одно число `interest`; окно —
минимум последнего платежа, конца доходов и `max_months`.

**Будет.** Закрытость по телу (правка 3: остаток части «тело»), в прокате —
погашение всех частей распределением платежей. `stalled` — та же формулировка
шире: платёж не покрывает начисляемое за период (проценты плюс неустойка).
Окно неустойка не продлевает: за окном начисленное не считается («не достигнута
за окно»). Начисленное месяца получает раскладку по видам (проценты, неустойка,
начисления-факты); записи-начисления проводятся в месяц события. Остаток
проката на конец месяца равен канону на ту же дату — итогом и по частям.

**Решения грилла плана.** Исполняет R3-Q21 (закрытость, равенство «прокат =
канон», `stalled`, окно, раскладка начисленного), правку 3 (закрытость по телу).
Новых решений не принимает.

**Blocked by:** 04 (части), 06 (неустойка), 08 (просрочка в проекции).

## Приёмка

- [ ] Синтетика: на концах месяцев остаток проката равен канону — итогом и по
  каждой части (книга с начислениями, разбивками и цессией внутри окна) —
  `tests/test_roll.py`.
- [ ] Синтетика: сделка с съеденным телом и висящими начислениями выходит из
  проката; сделка с растущим телом остаётся — `tests/test_roll.py`.
- [ ] Синтетика: платёж меньше начисляемого за период даёт `stalled`, а не
  ложную дату; окно с растущей неустойкой не продлевается — `tests/test_roll.py`.
- [ ] Синтетика: начисленное месяца раскладывается по видам, запись-начисление
  попадает в месяц события — `tests/test_months.py`.
