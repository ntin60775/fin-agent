# 03: Расписание долгов → касса — прокат месяцев

**What to build:** один вызов катает кассу на несколько месяцев вперёд. Долговая
сторона отдаёт расписание — список плановых платежей на период: дата, сумма,
финансирующий кошелёк, контрагент. Касса принимает расписание как данные и катает его
вместе с приходами, переводами, разовыми платежами и прожиточным минимумом. На
выходе — остатки кошельков по месяцам, дыры и их даты, нехватка до прожиточного
минимума, свободные деньги.

Свободные деньги месяца возвращаются долговой стороне как бюджет досрочек:
обязательства пересчитываются, расписание следующего месяца меняется — и так до
сходимости. Прогноз перестаёт держаться на числе, вписанном руками.

Месяцы календарные: первый — с даты старта до конца месяца, он неполный. Точка
отсчёта — дата и остатки кошельков — передаётся снаружи: движок не спрашивает
«сегодня» сам.

Если в середине дыра, прокат не останавливается и не уходит в минус молча: месяцы
после неё помечаются как посчитанные на допущении, что дыра закрыта.

**Blocked by:** 02 — прокат сделок.

- [x] Долговая сторона отдаёт расписание на период: дата, сумма, финансирующий кошелёк,
      контрагент
- [x] Касса катает N месяцев одним вызовом: остатки кошельков, дыра и её дата,
      нехватка до прожиточного минимума, свободные деньги — по каждому месяцу
- [x] Месяцы календарные; первый — с даты старта до конца месяца, неполный
- [x] Дата старта и остатки кошельков передаются снаружи: движок не обращается к
      «сегодня»
- [x] Месяцы считаются последовательно: остаток предыдущего — вход следующего
- [x] Свободные деньги месяца становятся бюджетом досрочек; обязательства
      пересчитываются, и расчёт повторяется до сходимости
- [x] Расчёт сходится за конечное число шагов; не сошёлся — ошибка с понятной
      причиной, а не тихий бесконечный цикл
- [x] Кроме расписания касса принимает разовые платежи — те, что не из сделок
      (например, передача семье); у них есть контрагент и назначение
- [x] Перенесённое и пропущенное вхождение учитывается при прокате на несколько
      месяцев, а не только в первом
- [x] Дыра не останавливает прокат и не уходит в минус молча: месяцы после неё
      помечены как посчитанные на допущении
- [x] События одного дня: доходы раньше платежей
- [x] Даты приходов считаются теми же правилами, что даты платежей: кламп на конец
      месяца и сдвиг назад по выходным
- [x] В ликвидность входят только доступные кошельки; арестованный или заблокированный
      показывается отдельно и деньгами не считается, и лимита к использованию не даёт
- [x] Платёж не финансируется недоступным кошельком: с карты, лимит которой закрыт
      банком, заплатить нельзя — её можно только гасить
- [x] Неизвестный прожиточный минимум даёт «не оценено», а не ноль
- [x] Синтетические тесты движка зелёные
- [x] Сценарные тесты потребителя зелёные — правка движка аддитивная, зона не сломана
