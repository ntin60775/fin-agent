# 08: Перенос существующих данных

**What to build:** старые данные раскладываются по новому формату без потерь. Первый
запуск идёт на них, а не на пустом месте, — иначе система права, но бесполезна.

Переносится: реестр взаиморасчётов, карточки контрагентов, кошельки, записи журнала,
месячные снимки бюджета. Каждая сделка получает уид, вид и ссылку на карточку;
фактический остаток переносится **с датой наблюдения** — без даты число нечего
сверять; расчётный остаток не переносится, он считается. Исходный кредитор и текущий
держатель разъезжаются по полям, скобки в имени перестают нести эту роль.

Проверка — **сверка, а не глаз**: число сделок, число карточек и суммарный остаток до
и после совпадают, а каждое расхождение объяснено записью, а не списано на округление.

Ничего не удаляется безвозвратно: старые файлы остаются в истории git, прошлый журнал
и прошлые месяцы уезжают в архив как есть — задним числом не переписываются.

**Blocked by:** 07 — форматы и карточки: переносить можно только в объявленный формат.

- [ ] Каждая сделка реестра получила уид, вид и ссылку на карточку контрагента
- [ ] Фактический остаток перенесён с датой наблюдения; расчётный считается, а не
      переносится
- [ ] Исходный кредитор и текущий держатель — отдельные поля, а не скобки в имени
- [ ] Кошельки заведены по схеме; остатки перенесены с датой наблюдения, доступность
      перенесена: видно, какими картами пользоваться нельзя и какие гасят
- [ ] Карточки заполнены по схеме; проза — история, переговоры, «что дальше» —
      сохранена целиком
- [ ] Записи журнала переведены в объявленный формат; прошлый журнал уехал в архив как
      есть и не переписывался
- [ ] Месячные снимки бюджета сохранили факты; производное из них убрано
- [ ] Сверка: число сделок, число карточек и суммарный остаток до и после совпадают;
      каждое расхождение объяснено
- [ ] Ни один старый файл не удалён безвозвратно — история в git
- [ ] Линт зоны чист
