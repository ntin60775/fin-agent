# 08: Перенос истории и сверка «до и после»

**What to build:** зона уже живёт по новым форматам — реестр, карточки, кошельки и
снимок месяца разложены тикетом 07. Осталось довести перенос до конца: собрать
**историю** и доказать, что она не потерялась.

**История движений.** Столбец `выплачено` сегодня несёт сводку «внесено по данным
кредитора»: отдельных движений за прошлое зона не вела, и сверка берёт эту сводку
как сумму движений. 08 собирает движения полями в журнале
(`- движение: сделка=… · сумма=… · дата=… · кошелёк=…`) — по выпискам, квитанциям
и записям зоны, — после чего сводка становится производной: `выплачено` = сумма
движений по сделке. Расхождение сводки с движениями перестаёт быть нормой и
становится вопросом.

**Сверка «до и после».** Число сделок, число карточек и суммарный остаток до и
после переноса сходятся, а каждое расхождение объяснено записью, а не списано на
округление. Считает код (`scenarios/report.py`), а не глаз: отчёт печатает
сходимость по каждому пункту, и это остаётся в нём, а не в протоколе разового
прогона.

**Архив.** Ничего не удаляется безвозвратно: старые файлы остаются в истории git,
прошлый журнал и прошлые месяцы не переписываются задним числом.

**Что уже сделано тикетом 07** — чтобы не переносить заново: сделки опознаются
уидом, вид и ссылка на карточку есть у каждой; фактический остаток перенесён с
датой наблюдения, расчётный считается кодом; исходный кредитор и держатель —
разные поля, а не скобки в имени; кошельки заведены по схеме; карточки заполнены,
проза сохранена целиком; снимок бюджета хранит факты; линт зоны чист.

**Blocked by:** 07 — форматы и карточки: переносить можно только в объявленный
формат.

- [ ] История платежей собрана движениями в журнале: у каждой сделки с платежами
      за прошлое есть движения, у остальных — пометка «движений нет, сводка по
      данным кредитора»
- [ ] `выплачено` стало производным от движений: расхождение сводки с движениями
      либо объяснено записью, либо стоит открытым вопросом
- [ ] Сверка «до и после» считается кодом: число сделок, число карточек и
      суммарный остаток сходятся, каждое расхождение объяснено
- [ ] Прошлый журнал (`log/2026-08.md`) и прошлый снимок месяца
      (`budget/2026-08.md`) не переписаны: остались как есть, история git это
      подтверждает
- [ ] Ни один старый файл не удалён безвозвратно — история в git
- [ ] Линт зоны чист
