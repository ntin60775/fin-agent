# 02: Прокат сделок — график, вхождения со статусами, копилка

**What to build:** прокат сделок по месяцам считает по списку вхождений, а не по
правилу на лету. Правило графика порождает вхождения — под закрытый набор форм:
фиксированная сумма с числом платежей, минималка процентом от остатка, несколько
дней в месяце, отдельный первый платёж. Поверх правила вхождение правится:
перенести, пропустить, изменить сумму.

У вхождения три даты — плановая (по графику, не меняется), перенесённая (когда
должен после договорённости) и фактическая (когда заплатили) — и статус. Прокат
читает статусы, а не правило: пропущенное не уменьшает остаток, перенесённое не
удваивается, исполненное заранее не считается дважды.

Даты считаются с оговорками: дня, которого нет в месяце, не бывает — берётся
последний; выходной сдвигает платёж вперёд по флагу правила графика; праздники не
учитываются.

Сделки, связанные единицей закрытия, работают как копилка: платежи не уменьшают
остаток, а копятся, и единица закрывается, когда накоплено не меньше суммы по всей
единице. Цель фиксируется при договорённости и не растёт.

Второй приоритет сам по себе не платится: прокат показывает свободный остаток и
предлагает направить его туда, а считать погашение начинает только после согласия
владельца.

**Blocked by:** 01 — модель взаиморасчётов.

- [ ] Правило графика порождает вхождения; поддержаны формы: фиксированная сумма с
      числом платежей, минималка процентом от остатка, несколько дней в месяце,
      отдельный первый платёж
- [ ] Поверх правила вхождение правится: перенести, пропустить, изменить сумму
- [ ] У вхождения три даты — плановая, перенесённая, фактическая — и статус
- [ ] Прокат считает по вхождениям и читает статусы: пропущенное не уменьшает
      остаток, перенесённое не удваивается, исполненное заранее не считается дважды
- [ ] Дня, которого нет в месяце, не бывает — берётся последний день месяца
- [ ] Выходной сдвигает дату по флагу правила графика: платёж — вперёд; праздники не
      учитываются
- [ ] Сделка без остатка не закрывается и не досрочивается: её платёж входит в
      обязательную нагрузку, но на дату выхода не влияет
- [ ] Правки вхождений приходят снаружи и применяются к порождённым: движок их не
      хранит, а получает
- [ ] Единица закрытия — копилка: платежи копятся, остаток не падает, цель
      фиксирована и не растёт, единица закрывается разом
- [ ] Прокат гасит только то, что должен я; сделки, где должны мне, в прокат не
      входят и перечисляются как ожидание
- [ ] Второй приоритет не платится автоматически: показывается свободный остаток и
      предложение направить его туда; погашение считается только после согласия
      владельца
- [ ] Пени отдельно не моделируются: рост при просрочке идёт по ставке сделки, а
      неизвестная ставка пени — пробел, а не ноль
- [ ] Освободившийся платёж остаётся в бюджете — эффект снежного кома сохранён
- [ ] Порядок досрочек — лавина (дорогая ставка первой) или снежный ком (мелкий остаток
      первым); стратегии сравниваются между собой, как и раньше
- [ ] Платёж меньше начисляемых процентов даёт честный «не закроется», а не ложный срок
- [ ] Прокат месячный: платежи внутри месяца агрегируются, по дням деньги считает
      касса (03)
- [ ] Сделки с дневной ставкой начисляют проценты по дням — перенос платежа внутри
      месяца стоит дни × дневная ставка; у годовой ставки начисление месячное, и
      перенос внутри месяца её не удорожает
- [ ] Синтетические тесты движка зелёные
