# 07: Зона — карточки контрагентов и форматы

**What to build:** карточки контрагентов живут в одной папке и описывают любого, с
кем есть взаиморасчёты: тип, подтип, группы, историю, переговоры. Реестр ссылается
на карточку, а не повторяет имя. Форматы объявлены в README папок: строка реестра и
запись журнала — со схемой столбцов и полей. Схему строки реестра и записи журнала
проверяет тест зоны, карточки проверяет линтер.

Правило «коллектор выводится вместе с исходным кредитором» перестаёт быть
соглашением об именовании: исходный кредитор и текущий держатель — разные поля,
скобки в имени больше не несут эту роль.

Фактический остаток в реестре — наблюдение извне: он вводится руками для сверки, и
расхождение с расчётным закрывается записью недостающих данных, а не правкой числа.
Сверка ищет причину, а не запрещает вводить факт.

**Blocked by:** 06 — схемы карточек: сначала схема, потом карточка.

- [x] Карточки контрагентов и реестр живут в одной папке, карточки кошельков — в
      своей; ссылки в правилах, командах и документах зоны перенаправлены
- [x] Карточки заполнены по схеме: тип, подтип, группы; проза сохранена
- [x] Реестр ссылается на карточки; исходный кредитор и текущий держатель — разные
      поля
- [x] Форматы строки реестра и записи журнала объявлены в README папок и проверяются
      тестом зоны
- [x] Сделки в реестре опознаются уидом; запись журнала ссылается на сделку
- [x] В реестре — фактический остаток на дату (введён извне) и расчётный по данным
      системы; расхождение не правится числом, а закрывается записью недостающих
      данных
- [x] Проверка падает на необъяснённом расхождении, а не на самом расхождении: либо
      есть объясняющая запись, либо открытый вопрос зафиксирован
- [x] Запись журнала бывает движением (деньги) и правкой вхождения (перенос, пропуск,
      смена суммы); состояние вхождения — производное от правила графика и записей
      журнала
- [x] Реестр — про взаиморасчёты, а не только про долги: в нём и долги, и регулярные
      расходы; у регулярного расхода остаток пуст
- [x] Карточки кошельков живут в своей папке и заполнены по схеме; реестр и сделки
      ссылаются на кошельки по уиду
- [x] У сделки есть вид — свободная метка со стартовым набором (рассрочка, заём,
      кредитка, цессия, регулярный расход); отчёты группируются по нему
- [x] В правилах зоны «финансирующий счёт» заменён на «финансирующий кошелёк»
- [x] Приборная панель зоны перестаёт быть рукописной: числа берутся из отчёта, а не
      переносятся руками — сегодня она дублирует реестр и уже расходилась
- [x] Месячный снимок бюджета хранит факты; производное — свободный остаток — из него
      убрано
- [x] Линт зоны чист
