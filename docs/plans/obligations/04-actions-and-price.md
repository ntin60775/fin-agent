# 04: Действия и цена варианта

**What to build:** правка сценария выражается объектом-действием: перенести платёж на
дату (или без даты — отложить), взять мост на N дней под ставку, погасить досрочно из
свободных денег месяца, направить свободный остаток. Вариант — список действий,
применённый к сценарию **целиком**: петля сходится после всего списка, а не после
каждого действия. Сценарий под вариант не переписывается.

Цена варианта показывается набором измерений, а не одним числом: рубли процентов
(сколько платишь или экономишь), дни просрочки, влияние на кассу (появилась дыра,
исчезла, стала глубже), сдвиг дат выхода и ступеней, изменение свободных денег.
Измерения разные, потому что действия разные: у переноса на два дня цена — дни
просрочки и минус дыра, у моста — рубли процентов.

Движок отклоняет только **невозможное**: сдвиг за горизонт, мост при отсутствии дыры,
мост больше доступного лимита кошелька, досрочка больше свободного остатка месяца,
конфликт действий внутри варианта.
Невыгодное не отклоняется — оно показывается ценой, а решение принимает человек.

Сам движок перебирает узкий набор: сдвиги платежей в окне и мост под дыру. Широкое
планирование — по запросу: список действий собирается снаружи.

Принятое действие становится фактом — записью в журнале (движение или правка
вхождения); сам объект-действие живёт только внутри варианта.

**Blocked by:** 03 — расписание и прокат месяцев.

- [ ] Действие — объект; поддержаны перенос платежа, отложение (перенос без даты),
      мост, досрочное погашение, направление свободного остатка
- [ ] Перенос ставит перенесённую дату вхождения; отложение — тот же перенос без даты,
      а не отдельный механизм
- [ ] Вариант — список действий, применяемый к сценарию целиком: петля сходится после
      всего списка
- [ ] Сценарий под вариант не переписывается
- [ ] Цена варианта — набор измерений: рубли процентов, дни просрочки, влияние на
      кассу, сдвиг дат выхода и ступеней, изменение свободных денег
- [ ] Мост — это новая сделка с условиями и движением по ней, а не отдельная сущность
- [ ] Досрочное погашение берёт деньги из свободного остатка месяца; сумма больше
      остатка — действие невозможно
- [ ] Досрочное погашение уважает единицу закрытия: сделку из единицы нельзя закрыть
      в одиночку
- [ ] Действие «направить свободный остаток» выражает согласие владельца: без него
      второй приоритет не считается погашаемым
- [ ] Мост берётся с кошелька только в пределах его доступного лимита: у недоступного
      кошелька лимита нет — больше него мост невозможен
- [ ] Отклоняется только невозможное: сдвиг за горизонт, мост без дыры, мост больше
      доступного лимита, досрочка больше свободного остатка, конфликт действий;
      невыгодное показывается ценой, а не отказом
- [ ] Сам движок перебирает сдвиги в окне и мост под дыру; широкое планирование —
      список действий снаружи
- [ ] Цена моста считается по переданной ставке; цена переноса — по базе начисления
      сделки: у дневной это рубли, у годовой — только дни. Числа в движок не вшиты
- [ ] Принятое действие записывается в журнал как факт; объект-действие в данных не
      хранится
- [ ] Синтетические тесты движка зелёные
