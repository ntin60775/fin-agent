# Решение: полный охват — модель распространяется на каждый документ зоны

- Дата: 2026-09-20
- Статус: принято
- Реализация: предстоит — расширение охвата проверки в линтере (пакет `ontoship`)
  и frontmatter документам вне `docs/`; до этого модель действует в границах
  `docs/**`.

## Контекст

Аудит базы знаний 2026-09-18 нашёл семь документов вне модели: `AGENTS.md`,
`CONTEXT.md`, корневой `README.md`, `finance_core/README.md`, `inbox/README.md`,
заявку в `inbox/` и правило `.omp/rules/inbox-first.md`. Ссылки в них проверяются
(I4 обходит все `.md`), а тип, свойства и сиротство — нет: линтер считает
несущими только документы `docs/**`. Дату последней правки не с чем сверить, и
именно в этих файлах аудит нашёл самые устаревшие места — дерево `.omp/` в
`AGENTS.md`, несуществующую команду в how-to-work.

## Варианты

1. **Узаконить исключение.** Модель действует в `docs/**`, корневые и пакетные
   документы объявлены вне её. Дёшево, но исключение из модели живёт хуже, чем
   его отсутствие: документ без типа — вне графа, вне индекса, без даты.
2. **Полный охват.** Привести проверку к обещанию модели — «every `.md`
   document is an object»: каждый документ зоны получает тип и свойства и
   участвует в инвариантах. **Выбран этот вариант.**

## Что это значит

- Frontmatter получают: `AGENTS.md`, `CONTEXT.md`, корневой `README.md`,
  `finance_core/README.md`, `inbox/README.md`, заявки в `inbox/`,
  `.omp/rules/inbox-first.md`.
- Типы (из словаря модели): README папок — `index`; `CONTEXT.md` — `reference`;
  `AGENTS.md` — `guide`; заявка — `reference`; правило зоны — `reference`.
- `finance_core/README.md` **остаётся рядом с кодом**: это README папки
  (`index`), а модель допускает README в любой папке. Перенос под
  `docs/services/` отклонён — обзор движка нужнее рядом с движком.
- Проверка расширяется в пакете `ontoship` (I1/I3 на все документы; формулировка
  I1 «every load-bearing doc» приводится к модели): модель меняется вместе с
  пакетом (I8), здесь — только исполнение.
- «Несущий документ» перестаёт быть границей охвата — граница: весь документ
  зоны.
