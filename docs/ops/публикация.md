# Публикация в открытый репозиторий

Зона спроектирована так, чтобы её **можно было публиковать**: личных данных в ней
нет — это и было причиной разделения ([zone-split.md](../decisions/zone-split.md)).
Технически стережёт **хук публикации** `.githooks/pre-push` (см. «Хук публикации»):
он блокирует push, если в отправляемых коммитах есть шаблоны личного.

## Что проверено

| Проверка | Результат |
|---|---|
| Личные числа, имена кредиторов, банки, номера счетов | нет: суммы без знака валюты вычищены 2026-09-15, имена и реальные суммы — 2026-09-28 (см. п. 1) |
| История коммитов | вычищена дважды: 2026-09-15 и 2026-09-28 (имена кредиторов, реальные суммы, сообщения коммитов); хеши после перезаписи изменились |
| Абсолютные пути `/home/…` в отслеживаемых файлах | нет (вычищены из истории 2026-09-28, см. п. 1) |
| Хук, блокирующий push | есть: `.githooks/pre-push` (подключён через `core.hooksPath`) — см. «Хук публикации» |
| `.gitignore` закрывает производное | `.gitmark/`, `*-map.html`, `.scratch/`, `__pycache__/`, `.forbidden-names.txt` |
| Ветка | `main` |
| Объём | 118 отслеживаемых файлов, ≈1,6 МБ — снимок 2026-09-28 |

## Факт публикации

Репозиторий опубликован: `origin` = `git@github.com:ntin60775/fin-agent.git`,
`main` в синхроне с `origin/main`.

## Как подготовить к публикации

1. **История.** Правка рабочего дерева историю **не чистит**. Проверяет **хук
   публикации** (см. ниже), а вручную — он же с полной областью:

   ```bash
   python3 .githooks/publication-check.py --all   # вся история: шаблоны, валюты, пути
   ```

   Хук ловит точные сигналы: шаблоны личного из `.forbidden-names.txt`, суммы со
   знаком валюты, абсолютные пути `/home/…`. Суммы **без знака валюты** шаблоном не
   отличаются от синтетических примеров движка: их хук печатает отдельным списком, и
   их смотрит человек — на этой слепой зоне утечка и проскочила, её нашли аудитами KB
   2026-09-15 и 2026-09-28. Найдётся — переписать историю **до публикации**. После
   первого push это уже невозможно: форки и кэши не отзываются.

2. **Лицензия.** Собственный код (`finance_core/`, тесты, документация) — **MIT**:
   [LICENSE](../../LICENSE). `.omp/` и `docs/ontology.md` — пакет **OntoShip** (MIT,
   © Valera Kovalskii): [LICENSES/ontoship-MIT.txt](../../LICENSES/ontoship-MIT.txt),
   авторство указано в `README.md`.

3. **README.md** — есть: что это, что умеет, принципы, происхождение.

## Хук публикации

`.githooks/pre-push` — проверка, которая стоит на `git push`. Область — только
отправляемые коммиты (их файлы и сообщения), поэтому на каждом push это дёшево.

| Сигнал | Реакция |
|---|---|
| шаблон из `.forbidden-names.txt` — имена кредиторов, реальные суммы | push остановлен |
| сумма со знаком валюты (`₽`, `руб`) | push остановлен |
| абсолютный путь `/home/<пользователь>/` | push остановлен |
| суммы без знака валюты, добавленные в `docs/` и `inbox/` | список «на глаза», push идёт |

Полная проверка и ручной запуск:

```bash
python3 .githooks/publication-check.py --all          # вся история
python3 .githooks/publication-check.py --range A..B   # диапазон коммитов
```

**Подключение** — в новом клоне один раз (в `.git/hooks` хук не версионируется):

```bash
git config core.hooksPath .githooks
```

Осознанный обход — `git push --no-verify`: тогда отвечает человек.

**Шаблоны личного — локальный файл** `.forbidden-names.txt` в корне: одна строка —
один шаблон, `#` — комментарий, совпадение по границам слова. Файл **не
публикуется** (`.gitignore`): сам список шаблонов — тоже личные данные, как учётки
инфобазы в 1С-проектах. Переносится на другую машину руками. Без него проверка имён
и сумм не работает — хук скажет об этом явно, а суммы со знаком валюты и пути
`/home/…` он ловит и без списка.

## Как опубликовать

```bash
cd fin-agent
git remote add origin git@github.com:<owner>/<repo>.git   # SSH, не HTTPS
git push -u origin HEAD
```

Если `origin` уже существует, `git remote add origin` падает — используйте
`git remote set-url origin git@github.com:<owner>/<repo>.git` или пропустите
шаг, если адрес верный.

**Из финансовой зоны push невозможен.** Её хук блокирует `git push` по шаблону
команды — в том числе нацеленный на этот репозиторий. Публикация идёт только из
сессии, открытой здесь; это не запрет, а страховка.

## Обратная сторона

Опубликованный репозиторий **публичен навсегда**: история, форки, кэши поисковиков.
Если позже понадобится закрыть — удаление не отменяет копий. Поэтому пункт 1
делается до, а не после.
