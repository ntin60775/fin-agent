# Перенос на другую машину

**Короткий ответ:** скопировать две папки — **почти** достаточно. Сами зоны
переносимы (внутри только относительные пути), но у системы есть части снаружи.

## Что копировать

Две папки **целиком, вместе с `.git/`** — история и локальная git-личность едут
внутри:

```
<куда угодно>/finance      ← финансовая зона
<куда угодно>/fin-agent    ← архитектурная зона
```

**Держать их соседями.** Финансовая зона находит движок по относительному пути
`../fin-agent` — проверено: без установленного пакета сценарные тесты проходят.
Разъехались — задать `FIN_AGENT_HOME=<путь к fin-agent>`.

Перед копированием можно вычистить производное (оно пересобирается):
`.gitmark/`, `.artifacts/`, `**/__pycache__/`.

## Что нужно на новой машине

| Что | Зачем | Проверка |
|---|---|---|
| **Агент `omp`** | его в папках нет — отдельная установка | `omp --version` |
| **Python ≥ 3.11** | движок и сценарии | `python3 --version` |
| **pytest** | тесты движка (сценарные тесты не требуют) | `python3 -m pytest --version` |
| **git** | коммиты; личность едет в `.git/config` | `git -C finance log -1` |
| **Ключ OCR** | только для `/ocr` | `NEURALDEEP_API_KEY` или `~/.omp/agent/models.yml` |
| SQLite ≥ 3.34 | для поиска (trigram); ниже — деградирует, но работает | `python3 -c "import sqlite3;print(sqlite3.sqlite_version)"` |

**Пользовательские навыки и правила** (`~/.omp/agent/`) в папки не входят: они
относятся к агенту, а не к проекту. Нужны — переносить отдельно.

## Проверка после переноса

```bash
cd fin-agent && python3 -m pytest tests/           # ждём зелёное: 327 passed (2026-09-28)
cd ../finance && python3 tests/test_scenarios.py   # сценарные тесты зоны — её цикл, см. ниже
cd ../fin-agent && python3 skill://kb-search/gitmark.py lint --strict
cd ../finance  && python3 skill://kb-search/gitmark.py lint --strict
```

`skill://kb-search/gitmark.py` разрешает агентская среда и ведёт к файлу пакета, где
бы тот ни стоял. В обычной оболочке инструмент лежит в кеше плагинов:
`~/.omp/plugins/cache/plugins/<пакет>/skills/kb-search/gitmark.py` — и в симлинке
`.omp/plugins/node_modules/ontoship/`. Флаг `--strict` обязателен: без него код
возврата нулевой и при ERR.

**Сценарные тесты зоны на 2026-09-28 красные** — 21 failed, 5 passed: зона не заполнила
дату начала долга, и валидация движка справедливо падает. Это её данные и её цикл,
перенос тут ни при чём; разбор — [how-to-work.md](../reference/how-to-work.md), шаг 6
цикла изменения движка.

Поиск: индекс пересобирается на новом месте, старый не переносить.

```bash
python3 skill://kb-search/gitmark.py index
python3 skill://kb-search/gitmark.py search "дыра"
```

## Необязательное: поставить движок пакетом

Сценарии и тесты работают и без этого. Установка нужна, если хочется импортировать
`finance_core` из любого места:

```bash
cd fin-agent && python3 -m pip install --user --break-system-packages -e .
```

## Чего переносить не надо

- `.gitmark/` — индекс поиска: пересобирается, содержит абсолютные пути.
- `.artifacts/` — эфемерный слой показа.
- `__pycache__/` — кэш байткода.
